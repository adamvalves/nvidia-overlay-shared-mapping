# Security Policy

## Scope & Target Platform

`nvidia-overlay-shared-mapping` documents inter-process memory sharing mechanics and access control analysis within Windows desktop sessions.

| Target Platform | Architecture | Status |
| :--- | :--- | :--- |
| Windows 11 (23H2 / 22H2) | x86_64 | Supported |
| Windows 10 (22H2 / 21H2) | x86_64 | Supported |

## Reporting Security Issues

To report uncontrolled memory safety issues, handle leakage, or privilege boundary concerns, please contact:

- **Security Contact**: `adam@networkconnect.org`
- **PGP**: Available upon request.
